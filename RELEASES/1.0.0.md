Esta branch preserva a versão considerada estável do Chess Arena antes do início do desenvolvimento da versão 2.0.

## Como voltar a esta base

No GitHub, abra a branch `stable/v1.0.0` e use-a como referência para comparar ou restaurar arquivos. Para restaurar o projeto inteiro, crie uma nova branch a partir do commit-base acima ou faça o revert dos commits posteriores na branch principal. Evite apagar ou sobrescrever esta branch.

## Escopo do marco

O marco inclui o código do site exatamente como estava no commit-base. Não representa um backup dos dados dos usuários no Supabase, nem uma exportação das configurações, secrets ou dados de produção.

## Regra de desenvolvimento

Novas funcionalidades devem ser desenvolvidas em branches separadas e testadas antes de serem incorporadas à branch principal.
